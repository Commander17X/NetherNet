Privacy policy

NetherNet does not have accounts, analytics, or tracking. Nothing you type is sent to a NetherNet account service, because there is not one.

What stays on the device

Saved servers, favorites, the relay address, an optional relay token, and cached server icons are stored only in local app storage on your phone or tablet. They are not uploaded to a NetherNet service.

Server status lookups

To show a MOTD, player count, version, icon, and ping, the app sends the server hostname and port to two public status APIs:

  • https://api.mcsrvstat.us first
  • https://api.mcstatus.io if the first lookup fails

That includes the featured server play.trix-islands.gg and any server you add. The app does this when the list loads, when you pull to refresh, on the server detail screen, during join, and when you tap Check while adding a server.

Your relay

Java servers are opened through a relay address you type in Settings. If you save one, the app calls that address for health, the public server list, and to start or check a session. A session request includes the server name, host, port, and whether login is online or offline. If you also save a relay token, it is sent as an Authorization header and stored only on the device.

Bedrock servers do not use the relay.

Opening the game

Join opens a minecraft:// link so the official Bedrock app can add the host and port. NetherNet does not collect a game account.

What we do not do

  • No accounts or sign-in
  • No analytics
  • No advertising or tracking
  • No sale of data

Questions go through GitHub issues.

NetherNet is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft.
